# 01 · 原理与版本选择

## Pluto 是什么

Pluto 是一个星际争霸 AI，由独立研究者 [tscmoo](https://github.com/tscmoo/pluto) 训练。

它和大多数人想象中的"游戏 AI"不一样：

- **3.15 亿参数的纯强化学习模型**，靠**自对弈**（左右互搏克隆体打了几百万盘）学出来
- **没有学过一盘人类录像**，也没有任何人工写的战术脚本（不是 rule-based bot），也不是模仿学习
- **不依赖大模型运行时**：作者手写了针对 x86 CPU 的 AVX2 SIMD 矩阵计算内核，权重是 int8 量化的，所以单次推理只要几十毫秒，**普通桌面 CPU 就能跑，不需要 GPU**
- **不吃屏幕像素**：它读的是游戏内存里的实体特征（单位血量、护盾、能量、武器冷却帧、朝向、命令状态机、迷雾可见性），而不是渲染画面

一个模型同时管宏观和微观，三个种族都会打。

## 先说清楚：为什么国内和国际的玩法不一样

暴雪 **2023 年退出中国大陆**，星际争霸重制版的国服**没有恢复** —— 国内玩家既上不了官方战网，也没有正规的购买和下载渠道。

这直接决定了本指南的形态：

- **经典版 1.16.1** 不需要任何联网服务，单机、局域网都能玩 → 国内完全可行
- **重制版**在国内容易联机的方式是走**国内对战平台**（KK 等），由平台提供房间和联机 → 本指南的重制版部分就是围绕这个写的
- 下面提到的"战网登录"那套流程，**在国服用不上**，看到可以直接跳过

不是多此一举，是国内唯一能联机的路子。

## 两种运行方式

Pluto 官方只支持一种运行环境：

```
星际争霸：母巢之战 1.16.1  +  BWAPI 4.4.0
```

（这是它自己 README 里 `Requirements` 写死的。）

于是有两条路：

### 路线 A：走 1.16.1（官方支持）

```
StarCraft 1.16.1
   └── BWAPI 4.4.0（注入 DLL，提供 AI 接口）
          └── pluto.dll（AI 模块）
                 └── pluto_infer.exe（64 位推理引擎，独立进程，通过共享内存通信）
```

这是 Pluto 被训练和参赛时用的环境，**成熟、稳定**。

### 路线 B：走重制版（社区桥接）

重制版（StarCraft: Remastered）是暴雪 2017 年重写的客户端，二进制完全不同，**BWAPI 不支持它**。

社区做了个桥接项目，思路很巧妙：

> **它不重写 Pluto**，而是把 **BWAPI 4.4.0 的接口** 和 **Pluto 直接引用的 Brood War 1.16.1 内存布局**，一起搭到重制版的运行时上。

也就是说：

- `pluto.dll` / `pluto_infer.exe` / 权重文件 —— **原样使用，一个字节都不改**
- 桥接自己 (`pluto-scr.dll` + `scr-loader.exe`) 负责把重制版的内存翻译成 1.16.1 的样子，让 Pluto 以为自己还在老引擎里
- 桥接只在**内存里**加载，退出即消失，**游戏文件和 Pluto 原文件都不被修改**

因为 Pluto 二进制是原样的，**桥接要用 SHA256 强校验**确保版本正确 —— 版本不对，内存偏移全错，注入即崩。

> ⚠️ 路线 B 是**实验性**的：上游作者自己标注"联机双端同步尚未验证完"，且原仓库已下架。详见 [03-重制版](03-重制版-安装与KK平台联机.md)。

## AI 看得见全图吗？（重要）

**不。Pluto 遵守战争迷雾，和你一样必须探路。**

这不是推测 —— 有人把 `pluto.dll` 反汇编了（[hwkim3330/pluto-re](https://github.com/hwkim3330/pluto-re)），文档里有一节标题就是结论：

> **Pluto respects fog of war.** 它直接读星际内存，但对**其他玩家状态**的每一次读取，都按 BWAPI 对普通（非作弊）机器人的方式做了门控。

具体来说：

| 项目 | 行为 |
|---|---|
| 敌方单位 | 只保留 sprite 可见性标志位含自己那一位的单位；未探测到的埋地单位一律丢弃 |
| 运输机/建筑里的敌方单位 | 从不读取 |
| 敌方扫描、子弹、闪电、核弹点 | 只取可见的 |
| 未探测的隐形单位 | 血量、护盾、命令、计时器、载员全部屏蔽 |
| 地图 | 菌毯和建筑占用只出现在**当前可见**的格子上 |
| 敌方经济与生产 | **完全不读** —— 矿、气、人口、单位数、科技、在研升级全部只索引自己；兵种、队列、建造进度、研究进度、能量、载员、幻象**只对自己单位发送** |

最后一条还特别点出：**它连敌方能量都藏了，而 BWAPI 本来是会给的** —— 它比一个标准 BWAPI 机器人还保守。

**这条结论可以放心讲给你的观众**：AI 赢是靠决策和操作，不是靠看穿地图。

## 版本选择建议

| 你的目的 | 建议 |
|---|---|
| 稳定长期用、做系列教学 | **1.16.1** |
| 想要现代画质、做演示内容 | 重制版（但接受它随时可能失效） |
| 想和真人朋友对战 | 两条线都行，1.16.1 甚至支持**同机双开**（见 [02](02-1.16.1-安装与同机联机.md)） |
| 想省事 | 1.16.1 |

**核心权衡**：重制版那条线的所有价值都建立在"暴雪不更新客户端"上。桥接锁死了 `1.23.10.13515` 这一个构建 —— 暴雪推一个无关紧要的小热更（哪怕只改一行字、把版本号 +1），内存偏移全部位移，注入后游戏直接闪退。

1.16.1 没有这个问题：它是 2009 年就冻结的版本，不会再有更新。

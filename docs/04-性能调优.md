# 04 · 性能调优

Pluto 的推理跑在 CPU 上（不需要 GPU）。**跑得快不快，几乎完全取决于你的 CPU 是否支持 AVX-VNNI。**

---

## 一、先判断你的 CPU

| 指令集 | 影响 |
|---|---|
| **AVX2** | **必需**。没有它跑不起来 |
| **AVX-VNNI** | **有则推理速度约翻倍**；Intel 12 代（2021）以后、AMD Zen 5 支持 |

跑一次自检就知道：

```powershell
.\scripts\scr\01-check-env.ps1
# 或
.\scripts\1161\01-check-env.ps1
```

也可以直接看推理引擎的自检输出 —— 日志里出现：

```
[engine] int8 blob: 133 tensors loaded pre-quantized (AVX2 madd fallback)
```

**`AVX2 madd fallback`** 就是"没有 VNNI，走回退路径"。

### 实测参考

| CPU | 200 单位 | 768 单位 |
|---|---|---|
| AMD Ryzen 7 3800X（Zen 2，无 VNNI） | **89.5 ms** | 265.6 ms |
| 作者验证用的现代桌面 CPU | 约 20 ms | — |
| 2021 年 6 核 i5-12500T | 约 60 ms | — |

模型的设计是**每 6 个游戏帧推进一步**（24 fps 下 = 250 ms），所以：

- **200 单位 89 ms** → 单看帧预算够用
- 但默认的**帧内预算是 40 ms**，89 ms 会溢出 → 游戏被拖慢

这就是"跟不上"的来源。

---

## 二、跑一次 bench，让它自己选线程数

```powershell
<游戏目录>\bwapi-data\AI\pluto\pluto_infer.exe --bench
```

它会把 4/6/8/10 线程都测一遍，选最快的写进 `pluto\pluto_config.json`。**以后推理引擎自动用这个配置**，不用再管。

输出示例（3800X，16 线程）：

```
int8mv   4              165.3 ms     515.1 ms
int8mv   6               98.3 ms     278.4 ms
int8mv   8              100.0 ms     294.1 ms
int8mv  10               89.5 ms     265.6 ms
[bench] chose backend int8mv, 10 threads -> pluto_config.json
```

**注意**：bench 会占满测试的线程数，跑的时候别开游戏。耗时约 2–4 分钟。

**线程数不是越多越好**：星际本身也要 CPU。16 线程的机器选 10 是合理的（留 6 个给游戏）。如果 bench 选得太满导致游戏卡，可以手工把 `pluto_config.json` 里的 `threads` 调低。

---

## 三、联机时的两个关键参数

这两个是**环境变量**，必须传给**游戏进程**（联机时游戏是平台拉起来的，所以要用平台启动器带上，详见 [03](03-重制版-安装与KK平台联机.md)）。

### `BWRL_STRADDLE=1`

**让 AI 永远不为了等推理结果而卡住帧**，晚到的决策顺延到后面的帧。

- **联机必开**。因为联机是网络锁步的，AI 卡帧会连累对手一起等 → 卡顿甚至掉线
- 代价：AI 决策频率略降（它选择"少做决定"而不是"让大家等"）

### `BWRL_FRAME_BUDGET_MS`

帧内给推理的时间预算，联机推荐 **10 ms**。

- 值越小，游戏越流畅，但 AI 的决策越容易顺延
- 值越大，AI 决策越及时，但游戏越可能被拖慢

### 怎么判断生效了

**关掉 STRADDLE 时**，游戏内会出现这句：

```
Pluto: this machine can't keep up (inference ~88 ms/step, stalling the game ~42 ms per decision)
```

**开着 STRADDLE 时这句不会出现。** 所以：

> 看到这句话 = 环境变量没生效（多半是设了变量但没重启平台）。

---

## 四、如果还是太慢

按影响从大到小：

1. **换 CPU** —— 唯一能带来质变的办法。带 AVX-VNNI 的机器大约快一倍
2. **降低线程数以外的干扰** —— 关掉后台占 CPU 的程序（浏览器、录屏软件）
3. **调 `BWRL_FRAME_BUDGET_MS`** —— 加大它会让 AI 决策更及时，但游戏可能被拖慢，自己权衡
4. **接受它** —— 模型设计上就是"推理慢则游戏慢，但 AI 不会因此变笨"（它只是在等自己的计算结果）

---

## 五、单机 vs 联机的速度差异

| | 单机（观战） | 联机 |
|---|---|---|
| 游戏速度 | 默认不限速（AI 多快就多快） | **由游戏控制**，AI 跟不上会拖慢 |
| 可用 `-SpeedMs 42` 定成正常比赛节奏 | ✅ | ❌（联机时该参数被忽略） |
| 需要 STRADDLE | 不需要 | **必需** |

单机观战时如果嫌太快看不清，用 `-SpeedMs 42`（对应天梯 Fastest 帧时）或 `-SpeedMs -1`（游戏默认速度）。

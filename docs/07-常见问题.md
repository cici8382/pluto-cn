# 07 · 常见问题（FAQ）

新人最常问的问题都在这。**装之前先扫一遍，能省掉大半的来回。**

---

## 一、值不值得搞

### 要花多少钱？

**软件全部免费。** Pluto、BWAPI、IPXWrapper、重制版桥接都不收钱。

唯一可能的花费是**游戏本体**：

- **经典版 1.16.1** —— 1998 年的老游戏，网上到处是
- **重制版** —— 需要你已经有（见下面「为什么国内这么麻烦」）

### 它有多强？

Pluto 是**纯自对弈强化学习**训练出来的 —— 3.15 亿参数，没有学过一盘人类录像，也没有任何人工写的战术脚本。它在星际 AI 比赛（CoG 2026）里正式参赛过。

实际体感：**中高水平的业余玩家基本打不过**，职业选手也要认真对待。它强在**零失误的多线操作**和**不合理的兵种配比** —— 人类会累、会手抖，它不会。

但别把它想成 AlphaGo：它有明显短板（比如处理运输机、多线骚扰时的判断会出问题），不是不可战胜的。

### 我这台电脑跑得动吗？

**三个硬指标，缺一不可：**

| 指标 | 要求 | 说明 |
|---|---|---|
| 系统 | Windows 10/11 **64 位** | 推理引擎是 64 位独立进程 |
| **CPU 指令集** | **必须有 AVX2** | 没有它**根本跑不起来**（不是慢，是起不来） |
| 内存 | 建议 2 GB 空闲 | 模型加载后常驻约 800 MB |
| 核心数 | 建议 6 核以上 | 推理和游戏抢 CPU |

**速度**取决于 CPU 有没有 **AVX-VNNI**：

- **有**（Intel 12 代以后、AMD Zen 5）→ 一步约 20–45 ms，流畅
- **没有**（大多数老 CPU，包括 Ryzen 3000 系列）→ 一步约 90 ms，**明显慢，会拖慢对局**

没把握就跑一次自检：

```powershell
.\scripts\1161\01-check-env.ps1
# 或
.\scripts\scr\01-check-env.ps1
```

它会直接告诉你 CPU 情况。详细调优见 [04-性能调优](04-性能调优.md)。

## 二、政策与风险

### 国内的战网能直接和它对战吗？

**不能。** 暴雪 2023 年退出中国大陆，**星际争霸重制版的国服没有恢复** —— 你既上不了官方战网，也没有正规的购买/下载渠道。

所以国内玩家要么：

- 玩**经典版 1.16.1**（单机 + 局域网，完全不需要联网服务）
- 在**国内对战平台**（KK 等）上约人玩，平台提供房间和联机

这也是为什么本指南的重制版部分要绕 KK 平台 —— **不是多此一举，是国内唯一能联机的路子。**

### 会不会被封号？

**看你用在什么地方。**

| 用法 | 风险 |
|---|---|
| 单机 / 自定义房间 / 约战 | 基本没有风险 |
| **公开排位、天梯匹配** | **有，而且不小** |

排位的风险来自两边：平台会封（封号通常是**账号连直播号一起处理**），对面玩家也会举报。而且这类工具的服务端行为特征很明显（同帧跨区域多线操作、无视视野下指令），想查一定查得出。

**所以：自定义房间没人举报，排位匹配一定有人举报。**

### 为什么要写那段「使用边界」？

因为这套工具**公开之后被拿去灌天梯是有先例的**（亚服那波就是）。

陪练和炸鱼是两件事：前者是学习和交流，后者是收割不知情的人。这个仓库帮的是前者。

## 三、装的时候

### 为什么不能做成"一个安装包"？

想省事的人一定会问这个。答案是**不能，也不建议**：

- **游戏本体是暴雪版权** —— 任何形式的打包分发都是侵权
- **Pluto 和重制版桥接都没有声明许可证**（法律上等于"保留所有权利"）—— 不能随包分发
- 桥接的**原仓库已经下架**，上游随时可能彻底消失

所以本仓库的形态是：**脚本负责「获取 + 校验 + 配置」，文档负责「讲清楚为什么」。** 组件从上游拿，版本靠 SHA256 锁死 —— 这个形态不会被下架，也不会让你的账号出事。

### Pluto 从哪下？release 里要下哪个文件？

见 [THIRD-PARTY.md](../THIRD-PARTY.md) 的完整说明。**关键点：**

- 从 `tscmoo/pluto` 的 **Releases** 页下载
- 需要的是完整发布包，解压后应该是这个结构：

```
pluto.dll                    ← 32 位 BWAPI 模块
pluto/
  pluto_infer.exe            ← 64 位推理引擎
  pluto_weights.bin          ← 权重（约 300 MB）
```

- **下完一定要校验**：本指南所有结论都基于 `md07x02_cog2026_2578600_int8mv` 这一个发布版，哈希对不上就跑不了

```powershell
.\scripts\1161\02-verify.ps1 -Pluto <pluto.dll 路径>
```

### GitHub 打不开怎么办？

国内访问 GitHub 时通时不通，这是常态。几个办法：

1. **多试几次** —— 本仓库的上传器就是带重试的
2. **用 Gitee 镜像** —— 本仓库在 Gitee 上有完整镜像，脚本和文档都能直接下
3. **让 git 走代理**（如果你有）：
   ```
   git config --global http.proxy  http://127.0.0.1:你的端口
   git config --global https.proxy http://127.0.0.1:你的端口
   ```

### 我想自己打 AI，该怎么装？

**这是最容易误解的地方，看清楚：**

| 你想干什么 | 需要什么 |
|---|---|
| **自己操作、和 AI 对打**（经典版） | 一台电脑，**同机双开**（本仓库的 IPX 方案），或者两台电脑 |
| **自己操作、和 AI 对打**（重制版） | ❌ **一台电脑做不到** —— 需要**两台电脑**，或者让 AI 跑在对手那台 |
| **看 AI 打电脑**（观战） | 一台电脑就够（经典版单机） |
| **让朋友来打 AI**（重制版 KK） | 一台电脑（你那台跑 AI）+ 朋友各自的电脑 |

**关键区别**：Pluto 是当成**一个独立玩家**参战的，它要占一个玩家位。所以"你 vs AI"必然需要两个客户端 —— 而重制版那两个客户端**不能在同一台机器上联机**（详见 [03-重制版](03-重制版-安装与KK平台联机.md) 开头的说明）。

经典版反而可以同机双开（本仓库有专门方案），这是它比重制版实用的重要原因之一。

## 四、玩的时候

### 进游戏后 AI 不动？

**先看日志，不要猜。** 两句话版本：

- **经典版** → `G:\starcraft_old\ipxwrapper.log`，应该有两个不同 `Node`，且都有 `bind address: .../6112`
- **重制版** → `桥接目录\runtime-multiplayer\bridge.log`，找 `session_accepted` / `session_skipped` / `bridge_exception`

最常见的三个原因：

1. **重制版建房时游戏方式不是 Melee** —— 只认 Melee（见 [03](03-重制版-安装与KK平台联机.md)）
2. **KK 把客户端设置改回 x86_64 了** —— 每次开 AI 前跑一次检测脚本
3. **联机环境变量没生效** —— 游戏里出现 `this machine can't keep up ... stalling the game` 就是它

完整对照表见 [05-排错手册](05-排错手册.md)。

### 第二局 AI 不动了？

**上游桥接的已知 bug**：对局末期会崩溃（访问违例），桥接一旦崩溃就死了，下一局自然没有 AI。

**绕过办法**：用 `-Watch` 监视模式，每局自动重新注入。

```powershell
.\scripts\scr\03-inject-kk.ps1 -Watch
```

### AI 说 "this machine can't keep up"？

你的 CPU 跟不上推理速度，游戏在等它。见 [04-性能调优](04-性能调优.md)：

- 跑一次 `pluto_infer.exe --bench` 让它自动选线程数
- 联机务必让 `BWRL_STRADDLE=1` 生效（这样 AI 不会拖住游戏）
- 根治只能换 CPU（带 AVX-VNNI 的能快约一倍）

### 我能中途接管 AI 的操作吗？

**能，但没意义** —— 你的指令会和 AI 的混在一起，结果是两边都不听使唤。

想观战就只移动画面，别下指令。

### AI 会看穿地图吗？

**不会，它遵守战争迷雾。** 这条有硬证据 —— 有人反汇编了 `pluto.dll`，结论是它对其他玩家状态的读取全部按 BWAPI 的可见性规则门控：敌方单位只在可见时读，敌方经济、生产队列、在研科技**完全不读**。它连敌方能量都不看（BWAPI 本来是会给的）。

详见 [01-原理与版本选择](01-原理与版本选择.md)。

## 五、其他

### 怎么卸载干净？

```powershell
# 1. 经典版同机联机建的那个账号
net user scai /delete

# 2. 影子目录（先确认里面是联接/硬链接，不会连带删原文件）
rmdir /s "G:\Pluto\1161\human"

# 3. 桥接目录
rmdir /s "G:\Pluto\scr"
```

原游戏目录（`G:\starcraft_old`）不受影响 —— 本指南的脚本从不修改游戏和 Pluto 的原文件。
